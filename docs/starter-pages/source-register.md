# Source Register

> Copy this file to `docs/topics/<topic-slug>/sources.md`. Give each source a stable ID (for example, `S1`) and use that ID in article references.

| ID | Title and author/publisher | Published or accessed | URL or supplied-file location | Use and limitations |
| --- | --- | --- | --- | --- |
| S1 | Replace with source title and author/publisher | Replace with date | Replace with URL or filename and page/section | Note what it supports and any relevant limitations |

Do not include private or confidential source content in the register. For supplied files, record only the minimum locator and description needed to identify the evidence, and confirm that the material may be published before including it in a public repository.
