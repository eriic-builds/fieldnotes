# Maintaining Documentation

Documentation needs review when the subject changes, a source is superseded, or an agent task is not adequately covered. Record the date of substantive edits in page metadata and preserve source publication dates and relevant applicability boundaries separately when they matter.

For an update:

1. Identify the change and the pages and agent tasks it affects.
2. Check authoritative sources for newer or corrected information.
3. Update affected pages and the source register; distinguish applicable versions or contexts and keep unresolved conflicts visible.
4. Check inbound and outbound links, regenerate the LLM index, validate, and build the site.
5. Review the rendered pages before publishing.

Do not imply that a page is current or universally applicable solely because its `last_updated` date is recent; verify the relevant facts and cited evidence.
