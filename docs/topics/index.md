# Product Documentation Collections

There are no product-specific documentation collections yet. When a product is selected, create a folder here using a descriptive lowercase slug, add its overview and source register, and link the collection from this page.

For each product, adapt the [topic overview](../starter-pages/topic-overview.md), [article](../starter-pages/article.md), and [source register](../starter-pages/source-register.md) starters. See the [research workflow](../guides/research-workflow.md) for how to gather and assess product material.
